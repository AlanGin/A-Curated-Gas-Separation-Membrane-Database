This repository builds a mechanism-aware membrane separation database infrastructure. Never write machine-extracted values directly into curated data. All extracted records must preserve provenance, including source PDF, DOI if available, page number, text/table/figure origin, raw string, normalized value, unit, extraction confidence, and validation status. Curated data may only be changed with an explicit diff report. The scientific goal is not a simple performance ranking table, but a condition-aware database for identifying reported upper bounds, operating boundaries, mixed-gas penalties, humidity penalties, aging/stability penalties, testing-condition bias, and transport-regime insights. Run validation checks before proposing changes.
