# Two-Dimensional Materials for Membrane Gas Separation

Initial curated literature seed set for mechanism-aware membrane separation data infrastructure.

This file intentionally stores citation metadata and DOI links only. It does not include publisher PDF copies.

## Scope

- Material families: graphene oxide, nanoporous/single-layer graphene, MOF nanosheets, COF nanosheets/framework membranes, MOF-in-COF hybrids, MXenes, LDHs, graphdiyne, and broad 2D membrane reviews.
- Gas separation targets: H2/CO2, H2/CH4, H2/N2, CO2/CH4, CO2/N2, natural-gas purification, hydrogen recovery, and carbon capture.
- Mechanism labels to extract later: molecular sieving, interlayer nanochannels, adsorption-diffusion, pore-size modulation, stacking/orientation effects, solution-diffusion, facilitated/affinity transport, and filler-polymer interface effects.
